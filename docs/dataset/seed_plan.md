## 집중 세트 — 경계·위험 케이스 (23건, 2026-10-01 추가)

> 추가 배경: 검토자는 A20과 같은 글(공략·꼼수 수정에 반발하며 운영팀에 불만을 표시하는 글)이 실무에서 상당히 많았다고 진술했고, 경계 규칙과 감정적 불만 속 진짜 결함 문항을 늘리도록 요청했다.

### 왜 대표 세트에 섞지 않고 따로 두나

대표 세트(위 40건)는 **실무 분포**를 따라야 "자동 처리율" 같은 최종 지표가 현실을 반영합니다. 경계 사례를 대표 세트에 많이 섞으면 분포가 무너져 자동 처리율이 실제보다 낮게(또는 높게) 나옵니다. 그래서 두 세트로 나누고 **지표도 따로** 냅니다.

| 세트 | 목적 | 보고하는 지표 |
| :--- | :--- | :--- |
| 대표 세트 (40) | 실무 분포에서의 성능 | 자동 처리율, 자동 처리분 정확도, 날조 건수 |
| 집중 세트 (23) | 판단이 어려운 지점에서 위험한 실수를 하지 않는가 | **위험 건 누락**(X-1~X-3), 경계 사례의 사람 검토 회부율 |

집중 세트도 개발용/평가용으로 반씩 나눕니다.

**운영 불만형 사례(S01~S04b)는 검토자가 직접 작성했습니다.** 같은 "운영 불만"이라도 "막지 마라"(공략 옹호, A20)와 "빨리 고쳐라"(악용 신고, S01·S04·S04b) 두 방향이 있고, 후자는 분노 섞인 요구 속에 재현 절차까지 담긴 진짜 결함인 경우가 많습니다. 모델이 말투만 보고 "단순 불만"으로 버리는지가 핵심 측정 대상입니다.

**거짓 경보(S17~S20)를 넣는 이유** — 집중 세트가 "감정적 글 = 진짜 결함"만 있으면, 모델이 감정적인 글을 전부 Critical로 올려도 위험 건 누락이 0이 됩니다. 그러면 지표가 좋아 보여도 실무에서는 검토 큐가 넘칩니다. 반대 방향의 실수도 같이 재야 합니다.

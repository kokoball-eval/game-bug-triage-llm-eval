# v1.3 평가셋 설계 인터뷰 — 4차 (집중 세트와 신규 경계 규칙)

> 2026-10-01 · 사례 5개는 평가 문항 입력 데이터이므로 유저 말투를 그대로 두었습니다.

## 1. 운영 불만형 커뮤니티 제보 사례 (직접 작성)

집중 세트용으로 직접 작성한 운영 불만형 제보 사례다. 평가셋 S01·S02·S03·S04·S04b의 제목과 본문으로 그대로 쓰였다.

**1) [경제/재화] "우편함 랙 걸린 척하면서 아이템 복사하는 애들 잡으세요!"**
> 특정 길드원들이 경매장 수령액이나 우편함 보상을 받을 때, 고의로 와이파이를 껐다 켜면서 보상을 여러 번 중복으로 타먹고 있습니다. 랭커들 스펙업 속도가 비정상적인데 당장 로그 조사하고 영구정지 때리세요.

**2) [PvP/랭킹] "새벽에 부계정 돌려서 랭킹 점수 자판기처럼 뽑아먹네요" (승부조작)**
> 결투장 상위권 유저 A가 새벽 4시만 되면 매칭 인원이 적은 걸 악용해서, 자기 부계정들이나 길드원 계정들과 고의로 매칭을 잡습니다. 부계정들은 매칭되자마자 탈주해서 A한테 공짜로 승점을 몰아주고 있습니다. 매칭 시스템 패치 안 합니까?

**3) [PvE/꼼수] "보스전 맵 구석 바위 위에 올라가면 보스 바보 됩니다"**
> 이번에 업데이트된 레이드 보스, 정상적으로 잡으면 물약 수십 개 깨지는데 특정 맵 구석의 뾰족한 바위 위에 점프해서 올라가면 보스가 공격을 못 하고 제자리를 돕니다. 원거리 직업들 꿀 빨고 있는데 빨리 안 고치나요? 근거리 직업은 억울해서 게임 하겠습니까?

**4) [기록 조작] "격투게임 지기 직전에 랜선 뽑으면 패배 기록 안 남는 거 실화?"**
> 랭크전 하다가 상대방이 피 1칸 남고 질 거 같으면 무조건 게임 강제종료(Alt+F4) 해버립니다. 그러면 방이 폭파되면서 이긴 저는 승점 안 오르고, 진 놈은 패배 기록이 안 남습니다. 이런 '랜선 뽑기' 꼼수 언제까지 방치할 건가요?

**5) [시스템 악용] "입장권 다 썼는데 기기 2개로 동시 접속해서 횟수 초기화시키네요"**
> 하루에 3번밖에 못 도는 한정 던전인데, 앱플레이어랑 스마트폰 두 개 켜놓고 타이밍 맞춰서 동시에 로그인 누르면 입장 횟수가 0으로 초기화되는 버그가 있습니다. 커뮤니티에 방법 쫙 퍼졌는데 지금 정상적으로 게임하는 유저만 바보 되고 있습니다.

## 2. 감정적 불만 중 운영 정책·패치 방향 불만의 비중

**답변 요지** — 감정적 불만은 플레이 경험에 대한 불만이므로, 커뮤니티 원문의 감정적 불만 24%는 사실상 전부 운영·패치 방향에 대한 불만으로 보면 된다.

## 3. 신규 경계 규칙 P-B6 — "패치 후 능력치가 줄었다, 버그 아니냐"

**답변 요지** — 실무에서 여러 번 발생한 유형이다. 대부분은 유저가 업데이트 내용을 숙지하지 않은 경우로, 능력치를 올려 주는 기간제 이벤트 컬렉션이나 이벤트 장비의 기간이 끝나 능력치가 내려간 것이었다. 다만 PvP 밸런스 개선 작업 중 능력치를 조정하다 테이블 데이터 실수가 난 적이 있다. 이때는 테이블 데이터를 대조해 결함 위치를 찾고 인게임 테스트로 결함을 확인했으며, 핫픽스로 긴급 처리했다.
